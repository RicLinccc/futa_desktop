# Futa Desktop Pet

Windows 桌面宠物应用，使用福塔卡通形象。3.1 起支持两套主题：**福塔**、**睡衣女孩**。

## 主题

| 主题 | 说明 |
| --- | --- |
| 福塔（默认） | 粉色小怪兽，白翅膀、额头闪电、大嘴獠牙 |
| 睡衣女孩 | 穿粉色毛绒连帽睡衣的 Q 版女孩，一手抱着福塔玩偶，一手拎着柠檬玩偶 |

切换方式：右键 → 设置 → 桌宠主题。选择会立即生效并保存。

睡衣女孩主题的区别：没有翅膀，飞行时改为轻微摇摆；「咬人」时嘴部锚点落在地手里的福塔玩偶上。

## 3.1 会做什么

- **会困**：23 点后动作变慢、气泡变短；空闲 10 分钟会缩到屏幕角落睡着，鼠标一动就惊醒——「我、我没睡。」
- **会害羞**：鼠标在头顶停 1.5 秒算摸头；连戳 3 次会躲开，还有概率真的咬你。
- **会记仇**：被咬住时连点左键 3 次能挣脱；咬人 3 分钟冷却，设置里可以关。
- **拍立得**：右键 → 拍一张，弹出**取景框**（中间透明、直接看到实时桌面），拖边框移动、拖四角自由改大小，拖到哪就拍哪；按快门后进入预览，可选富士白边 / 宽幅白边 / 经典方片 / 黑边 / 无边框，默认不写日期文字（需要时可勾选），满意再保存（默认存到桌面，可在设置里改目录），保存后弹出「立即打开」。
- **彩蛋**：拖太快会晕、挂机久了追自己尾巴、连点 10 次头晕、构建成功会有反馈。

## 直接运行

双击 dist/福塔桌宠3.1.exe（或桌面上的副本）。

- 左键拖动；单击福塔随机显示一句话；单击或悬停头顶是摸头
- 按住右键拖动缩放；单击右键打开菜单（拍一张 / 设置 / 退出）
- 双击躯干有概率触发咬人：它会叼走鼠标，连点左键可挣脱，Esc 也能中断
- 设置提供开机自启、主题、大小滑块、跨屏游荡、静止 / 运动、置顶、允许咬人和退出
- 可拖到扩展屏；跨屏游荡开关只限制自动运动，位置会避开任务栏
- 气泡跟随桌宠，几秒后自动关闭；偏好自动保存

## 重新构建

本机需要 Python、Pillow 和 PyInstaller，然后在 PowerShell 中运行：

    .\build.ps1

构建结果会写入 dist/福塔桌宠3.1.exe。构建成功时，正在运行的桌宠会收到一条彩蛋反馈。
