## 2. 主题：不换衣服，换作息

「睡衣福塔」在本期不是一套皮肤，而是一组行为：夜里变慢、说话变短、会打瞌睡、被你吵醒会心虚。

等以后有美术，再把睡衣真正穿上——那是 3.1，不是 3.0 的门槛。

## 3. 六个玩法

### 3.1 夜猫子（P0 · 低成本）

- **触发**：本地时间 23:00 后；或系统空闲 10 分钟。
- **表现**：飞行速度 ×0.6；台词切「困」池；每 90 秒冒一个 zzz 飘字；空闲 10 分钟 → 飞到屏幕角落，立绘调暗 15%、缩小 5%，进入睡着。
- **惊醒**：鼠标一动 → 弹起 + 抖两下 + 气泡「！」，台词「我、我没睡。」
- **早晨**：07:00–09:00 第一次交互 → 伸懒腰（纵向拉伸 8% 再回弹）。
- **为什么好玩**：它陪你熬夜，还怕被你发现它在偷睡。
- **实现**：系统时间 + GetLastInputInfo + PIL 调暗 + 现有动画循环，零新素材。

### 3.2 柠檬玩偶（按需求延后，本期未实现）

- **道具**：PIL 现画一个扁平风柠檬（果身 #F6E27A、描边 #C79A2E、3 片叶子、2 个高光点），放在右下角的小碟子上。
- **咬**：点柠檬 → 福塔飞过去咬，牙印 +1，气泡「酸——」；第 3 口吃完，柠檬消失。
- **刷新**：次日 08:00 出现新柠檬（仪式感）。
- **抢 / 藏**：拖起来甩出 → 抛物线 + 弹两次；拖到屏幕边缘外 → 它张望 8 秒 + 头顶问号，45 秒后给方向暗示「左边。我什么都没说。」
- **睡**：夜里抱着柠檬。
- **为什么好玩**：这是它的东西，你可以欺负它——它会有反应。
- **实现**：canvas 多一个 item + 20 行物理积分 + 状态写进 settings.json。

### 3.3 摸头 / 戳脸（P0 · 低成本）

- **悬停头顶 1.5 秒**：眯眼（整图压扁 4%）+ 心形/星星飘字 + 台词。
- **连摸 5 次**：稀有台词 + 服帖 1 秒。
- **快速戳脸 3 次**：皱眉（横向压扁）+ 躲开 + 「再戳我就咬你了」——然后真的咬。
- **为什么好玩**：它记得你怎么对它。

### 3.4 拍立得（P0 · 低成本）

- **触发**：右键菜单「拍一张」。
- **过程**：0.4 秒摆姿势（缩放 + 抖）→ 窗口内白闪 3 帧 → PIL 合成拍立得（白边、日期、一句台词、−3° 倾斜）→ 存到「图片\福塔相册」。
- **展示**：桌面弹出一张可拖动的相框贴纸（Tk 小窗口 + 缩略图），点开看大图；最多 3 张。
- **为什么好玩**：把「这一刻」留下来；也是唯一能发出去炫耀的东西。

### 3.5 咬人 3.0（P0 · 低成本）

- **保留** 2.0 的 chase / carry / return，中间插一段 struggle：被叼住时快速晃鼠标可挣脱，它愣 0.5 秒。
- **优先叼柠檬**：光标旁有柠檬时先叼柠檬。
- **收尾**：放下后舔嘴 + 得意 1.5 秒。
- **边界**：冷却 3 分钟；设置里可完全关闭「咬人」。
- **为什么好玩**：从「它欺负你」变成「你们互相欺负」。

### 3.6 彩蛋（P1 · 低成本）

- 拖得太快 → 眼冒金星（「× ×」文字 + 转圈）。
- 挂机 20 分钟 → 追自己尾巴绕圈飞。
- 连点柠檬 10 次 → 柠檬长出小眼睛，对视 2 秒。
- build.ps1 结束时通知 → 成功撒星星，失败捂脸冒烟。

## 4. 状态与时间表

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| idle | 默认 | 呼吸、眨眼、偶尔张望 |
| curious | 光标 300px 内 | 头跟随 |
| eating | 点在柠檬上 | 飞过去咬，牙印增加 |
| guarding | 连续被抢柠檬 | 把柠檬护在怀里，背对你 |
| sleepy | 23:00 后或空闲 5 分钟 | 变慢、zzz、眼皮（整图微压） |
| asleep | 空闲 10 分钟 | 角落睡，调暗 + 缩小 |
| startled | 睡着时鼠标动 | 弹起 + 抖 + 「！」+ 装没事 |
| biting | 双击躯干 | 追光标 → 叼走 |

时间表：23:00 变困 / 空闲 10 分钟入睡 / 07:00–09:00 起床气。全部内部值，不暴露成数值面板。

## 5. 台词

文案规则：先示弱半拍、再反转成坏；单行 ≤ 16 个汉字、每条 ≤ 2 行；不用 emoji（Tk 渲染差）。

**夜间**

- 十二点了。你还不睡，我就替你睡。
- 别关我。关了我也在，只是你看不见。
- 我先眯一会儿。有事……明天再说。

**被抓包**

- 我、我没睡。我在思考。
- 你动静小点。我刚梦到柠檬。

**柠檬**

- 酸——！……但是还想咬。
- 那是我的。（抱紧）
- 你看见我的柠檬了吗？没有？真的没有？

**摸头 / 戳**

- 再摸就收费。
- 再戳我就咬你了。（已经咬了）
- 算了。你摸吧。

**拍照**

- 站好，别动。我数三下——三。
- 这张不许删。删了我也记得。

**被拖拽 / 没人理**

- 放我下来！……好吧，这里风景不错。
- 你忙你的。我就坐在这里。
- 喂。……喂。

## 6. 技术口径：为什么不用换底座

现有 2.0 已经能支撑上面全部玩法，只是没被用起来：

| 玩法 | 用现有的什么 |
| --- | --- |
| 夜猫子 | 系统时间、GetLastInputInfo（ctypes）、render_frame 前对帧做 PIL 调暗、现有 60fps 循环 |
| 柠檬 | canvas 多一个 image item、PIL 画图、手写 20 行重力/反弹、move_inside 复用 |
| 摸头/戳脸 | canvas 的 Motion 事件 + 头部矩形判定 + 整图缩放 |
| 拍立得 | PIL 合成、Toplevel 相框、现有气泡代码当模板 |
| 咬人 3.0 | 现有 chase/carry/return 状态机里插一个 struggle 分支 |
| 彩蛋 | 现有事件 + 计时器 |

**顺手修三个坑**（都跟新玩法直接相关）：

1. 静止时完全不推进动画帧（animate 第 304 行）——不修，打瞌睡会像卡死的图。
2. after 链没有异常保护（第 312 行）——一次异常会让宠物永久卡死。
3. 气泡是独立 Toplevel，拍立得预览可复用同一套定位逻辑。

**明确不做**：分层窗口、逐像素 alpha、皮肤包、多屏 DPI 重做、窗口停靠。这些没有一个是「好玩」的必要条件。

**改动规模**：约 +400~600 行，新增 3 个小类（LemonProp / SleepSchedule / PhotoBooth），其余在现有事件里加状态。

## 8. 边界

- 不做负罪感设计（不惩罚、不装可怜、不深夜弹窗）。
- 声音默认关；咬人默认开但可关。
- 不联网、不读剪贴板、不扫桌面文件。
- 所有打扰（提醒、夜猫子、咬人）都能在设置里关掉。
