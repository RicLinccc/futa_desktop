# 福塔桌宠 3.1 · 拍立得

> 右键 → 拍一张：先预览，再决定要不要保存。照片背景是拍摄那一刻的真实桌面，不是纯色底；桌宠会自动居中。

## 1. 流程

1. 右键点击桌宠 → 拍一张（或设置面板里的「拍一张拍立得」）。
2. 弹出**取景框**：中间完全透明，直接看到实时桌面；拖住上边框或四周边框移动，拖四角的粉色方块自由改大小；拖到哪、框多大，快门就拍哪。
3. 按「快门」：桌宠和取景框会瞬间隐身，截下取景框圈住的真实桌面，再把桌宠合成回去（在框内就按原位放，不在框内就居中）。
4. 弹出「拍立得预览」窗口，可切换样式、看效果。
5. 点「保存」才写入文件；点「取消」什么都不留下。
6. 保存成功后桌面右下角浮窗提示：截图已保存到「桌面」（默认，可在设置里改目录），并提供「立即打开」「打开文件夹」。

取景框的操作：拖深色边框移动；拖四角粉色方块改大小（最小 320×300，不会超过屏幕）；右上角「快门」拍照，「取消」关掉；中间的透明区域就是实时桌面，看到的构图就是拍出来的构图。

## 2. 内置样式

| key | 名称 | 说明 |
| --- | --- | --- |
| fuji | 富士白边 | 默认样式，白边 + 加厚下边距，最接近富士拍立得；默认不写日期文字 |
| wide | 宽幅白边 | 横向构图，适合拍桌面 |
| classic | 经典方片 | 更厚的边框，偏复古 |
| dark | 黑边 | 深色边框，夜间/深色壁纸好看 |
| minimal | 无边框 | 只留极窄白边，适合直接当截图用 |

## 3. 新增一种样式

在 src/futa_pet.py 的 PHOTO_TEMPLATES 里加一条即可，不用改流程代码：

    "my_style": {
        "name": "显示名称",
        "canvas": (560, 700),        # 整张相纸尺寸
        "border": (36, 36, 36, 128), # 左、上、右、下 四边宽度
        "bg": (252, 251, 247),       # 相纸颜色
        "text": (128, 112, 116),     # 文字颜色
        "line": (226, 222, 214),     # 照片与相纸之间的细分隔线，可为 None
        "caption": True,             # 模板是否支持文字；实际由预览里的「写日期/文字」勾选控制，默认关闭
    }

保存时会把当前选择传给 build_polaroid，照片区域自动按比例裁切，不会变形。

日期与文字默认不写：预览窗口左下角有「写日期/文字」勾选，需要时才打开；生成的图片本身不带任何水印，方便你自己后期加。

## 2.5 照片存到哪里

- 默认保存到**桌面**。
- 设置面板 → 照片保存目录 → 选择 可改成任意文件夹；也可以直接输入路径。
- 「恢复默认（桌面）」一键改回。
- 目录会记住，下次拍照继续用。

## 4. 背景与隐私

- 每张照片都是「拍下那一刻的真实桌面」：先隐藏桌宠，抓取它所在的整个工作区，再把桌宠合成回去，所以背景里会出现你当时开着的窗口、壁纸和图标。
- 照片只保存在本地「图片\福塔相册」，不上传、不联网。
- 如果介意隐私，拍照前先把不想入镜的窗口最小化；也可以选择「无边框」样式当普通截图用。

## 5. 技术备注

- 高分屏下 Tk 坐标是逻辑像素，截图是物理像素，拍照时会按屏幕缩放比换算，避免照片内容错位。
- 桌宠会按它当前在屏幕上的位置自动取景；想让它居中，拍照前把它拖到屏幕中间即可。
- 预览窗口不阻塞主程序，关掉预览不会保存任何文件。
